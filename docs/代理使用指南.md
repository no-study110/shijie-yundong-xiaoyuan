# 代理使用指南

## 概述

协议套件完整支持 HTTP/HTTPS/SOCKS5 代理,可用于:
- **IP 归属地隐藏**: 使用本地代理或境内代理池避免异地 IP 风控
- **网络环境切换**: 模拟校园网/移动网络环境
- **并发隔离**: 多账号使用不同代理分散请求特征

## 代理协议支持

| 协议        | 地址格式                        | 说明                  |
|-------------|--------------------------------|-----------------------|
| HTTP        | `http://host:port`             | 明文 HTTP 代理        |
| HTTPS       | `https://host:port`            | 加密 HTTPS 代理       |
| SOCKS5      | `socks5://host:port`           | SOCKS5 代理(推荐)     |
| 带认证 HTTP | `http://user:pass@host:port`   | 需要用户名密码的代理  |
| 带认证 SOCKS5 | `socks5://user:pass@host:port` | 需要用户名密码的代理  |

## 使用方式

### 1. 代码方式

```python
from sport_client import SportClient792

# 使用 HTTP 代理
client = SportClient792(proxy="http://127.0.0.1:7890")

# 使用 SOCKS5 代理(推荐,协议兼容性更好)
client = SportClient792(proxy="socks5://127.0.0.1:1080")

# 使用需要认证的代理
client = SportClient792(proxy="http://username:password@proxy.example.com:8080")

# 正常使用
res = client.login("账号", "密码")
if res.success:
    run_res = client.execute_run(target_distance_m=2100, target_time_sec=780)
```

### 2. Web UI 方式

```bash
# 启动 Web UI
python webui.py
```

访问 `http://127.0.0.1:9999` 后:
1. 点击右上角 "设置" 图标
2. 在 "代理配置" 框填入代理地址,如 `http://127.0.0.1:7890`
3. 点击 "保存代理设置"
4. 配置立即生效,所有后续请求都经过该代理

**清除代理**: 留空保存即可恢复直连

## 常见代理工具

### Clash/Clash Verge
- **默认端口**: `http://127.0.0.1:7890`
- **配置**: 开启「允许局域网连接」
- **推荐场景**: 本机使用,稳定性高

### V2Ray/V2RayN
- **默认端口**: `socks5://127.0.0.1:10808` (SOCKS5) 或 `http://127.0.0.1:10809` (HTTP)
- **配置**: 开启「允许来自局域网的连接」
- **推荐场景**: 灵活配置,支持多种协议

### 代理池服务
```python
# 使用付费代理池(需确保代理在校园同城/同省)
import requests

# 从代理池获取一个本地 IP 代理
pool_api = "http://proxy-pool.example.com/get?city=杭州"
proxy_url = requests.get(pool_api).json()["proxy"]

client = SportClient792(proxy=proxy_url)
```

## 风控建议

### 最佳实践
1. **优先使用校园同城代理**: 避免跨省 IP 触发异地登录风控
2. **单账号固定代理**: 同一账号尽量使用同一代理地址,避免 IP 频繁切换
3. **代理质量检查**: 使用前测试代理延迟(<300ms)与稳定性

### IP 归属地匹配
```python
# 示例: 浙江大学账号应使用浙江省内代理
# 某些学校会验证 IP 归属地与学校所在省份是否一致

import requests

def check_proxy_location(proxy_url):
    """检查代理 IP 归属地"""
    try:
        resp = requests.get("https://ip.taobao.com/outGetIpInfo", 
                           params={"ip": "myip", "accessKey": "alibaba-inc"},
                           proxies={"http": proxy_url, "https": proxy_url},
                           timeout=5)
        data = resp.json()
        province = data["data"]["region"]
        city = data["data"]["city"]
        print(f"代理 IP 归属: {province} {city}")
        return province, city
    except Exception as e:
        print(f"检查失败: {e}")
        return None, None

# 使用前检查
check_proxy_location("http://127.0.0.1:7890")
```

### 多账号场景
```python
# 为每个账号分配不同代理,避免关联
accounts = [
    {"username": "user1", "password": "pass1", "proxy": "http://proxy1:8080"},
    {"username": "user2", "password": "pass2", "proxy": "http://proxy2:8080"},
]

for acc in accounts:
    client = SportClient792(proxy=acc["proxy"])
    res = client.login(acc["username"], acc["password"])
    if res.success:
        client.execute_run(target_distance_m=2100, target_time_sec=780)
```

## 故障排查

### 问题 1: 代理连接超时
**现象**: `urllib.error.URLError: <urlopen error [Errno 10060] 由于连接方在一段时间后没有正确答复或连接的主机没有反应，连接尝试失败。>`

**解决**:
1. 检查代理地址与端口是否正确
2. 确认代理软件已启动且监听正确端口
3. Windows 防火墙是否允许代理软件联网
4. 尝试 `curl -x http://127.0.0.1:7890 https://www.baidu.com` 测试代理可用性

### 问题 2: 代理认证失败
**现象**: `HTTP 407 Proxy Authentication Required`

**解决**:
- 代理地址需包含用户名密码: `http://user:pass@host:port`
- 密码含特殊字符需 URL 编码: `pass@123` → `pass%40123`

### 问题 3: SOCKS5 代理不可用
**现象**: `urllib.error.URLError: <urlopen error unknown url type: socks5>`

**解决**:
```bash
# 安装 PySocks 库以支持 SOCKS 协议
pip install PySocks
```

## 技术细节

### 代理传递路径
```
SportClient792(proxy="...")
    ├─ LoginClient(proxy=proxy)          # 登录请求
    ├─ ProfileClient(proxy=proxy)        # 个人资料
    │   └─ BaseNetSecClient(proxy=proxy)
    ├─ PolicyClient(proxy=proxy)         # 跑步规则
    │   └─ BaseNetSecClient(proxy=proxy)
    ├─ HistoryClient(proxy=proxy)        # 历史记录
    │   └─ BaseNetSecClient(proxy=proxy)
    └─ RunningClient(proxy=proxy)        # 跑步提交
        └─ BaseNetSecClient(proxy=proxy)
```

所有 HTTP 请求(包括华为云 OBS 上传)都会经过配置的代理。

### ProxyHandler 实现
```python
# core/client.py: BaseNetSecClient.execute_request()
if self.proxy:
    proxy_handler = urllib.request.ProxyHandler({
        "http": self.proxy,
        "https": self.proxy
    })
    opener = urllib.request.build_opener(proxy_handler, ...)
```

## 安全提示

1. **不要使用免费公共代理**: 存在流量窃听风险,可能导致账号密码泄露
2. **避免使用境外代理**: 延迟高且容易触发异地登录风控
3. **代理日志清理**: 使用后及时清理代理软件的访问日志

## 完整示例

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""完整代理使用示例"""

from sport_client import SportClient792

def main():
    # 使用本机 Clash 代理(确保 Clash 已启动)
    PROXY_URL = "http://127.0.0.1:7890"
    
    client = SportClient792(proxy=PROXY_URL)
    
    # 登录
    print("正在通过代理登录...")
    login_res = client.login("账号", "密码")
    if not login_res.success:
        print(f"登录失败: {login_res.message}")
        return
    
    print(f"✓ 登录成功: uid={login_res.uid}")
    
    # 查询规则(测试代理连通性)
    print("正在通过代理查询跑步规则...")
    rule = client.get_run_policy()
    if rule:
        print(f"✓ 规则获取成功: 最低{rule.min_distance}m, 配速{rule.speed_range_text()}")
    
    # 提交跑步(所有请求都经过代理)
    print("正在通过代理提交跑步记录...")
    run_res = client.execute_run(
        target_distance_m=2100,
        target_time_sec=780,
        sport_type=1,
        realism=True
    )
    
    if run_res.success:
        print(f"✓ 提交成功: rrid={run_res.rrid} 判定={run_res.status_text}")
    else:
        print(f"✗ 提交失败: {run_res.message}")

if __name__ == "__main__":
    main()
```

**常见问题**: 代理配置后仍被风控?
- 检查代理 IP 归属地是否与学校同省
- 单账号避免频繁更换代理 IP
- 配合拟真增强(`realism=True`)使用
- 控制提交频率(建议每日 1-2 次,间隔>4 小时)
